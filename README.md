# Project 2 – Employee Payroll and Deduction Analysis

## Description
The Employee Payroll and Deduction Analysis System is a Python-based project that calculates an employee's salary using basic pay, house rent allowance (HRA), dearness allowance (DA), overtime payment, and incentives. It also calculates salary deductions and displays the final net salary.

## Objectives
- Calculate employee allowances.
- Calculate overtime payments and incentives.
- Determine the gross salary.
- Calculate total salary deductions.
- Generate the final net salary statement.

## Concepts Used
- Variables and Data Types
- User Input
- Arithmetic Operators
- Conditional Statements
- Basic Mathematical Calculations

## Salary Calculation Assumptions
- HRA = 20% of Basic Salary.
- DA = 10% of Basic Salary.
- Overtime Payment = ₹100 per hour.
- Deduction = 5% of Gross Salary.
- Incentive is entered by the user.

## Sample Output
```text
Enter Employee Name: Ravi
Enter Basic Salary: 25000
Enter Overtime Hours: 10
Enter Incentive: 2000

Employee Name: Ravi
Basic Salary: Rs. 25000.00
HRA: Rs. 5000.00
DA: Rs. 2500.00
Overtime Pay: Rs. 1000.00
Incentive: Rs. 2000.00
Gross Salary: Rs. 35500.00
Total Deduction: Rs. 1775.00
Net Salary: Rs. 33725.00
```

## How to Run
1. Open the project folder in VS Code.
2. Open the Python source file.
3. Run the program.
4. Enter employee name, basic salary, overtime hours, and incentive.
5. View the calculated salary details.

## Conclusion
This project demonstrates the practical use of Python to calculate employee salaries, allowances, overtime payments, and deductions. It helps understand variables, arithmetic operators, and basic programming concepts.
